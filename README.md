# Actor requests

Request a new data tool or a variant of an existing one. Everything built here ships as a **pay-per-result Actor on the Apify Store** — you pay only for the rows you get, nothing up front, no account with us.

**→ [Open a request](../../issues/new?template=request.yml)**

How it works
1. You describe the data you want (site or API, fields, how often).
2. An automated triage replies within a day: queued, needs review, or declined (we only build from public, login-free sources and never collect personal data about private individuals).
3. Queued requests ship within a few days; the issue gets the Store link when it's live.

Live catalog: https://apify.com/eze007

Bugs in an existing Actor: use the **Issues** tab on that Actor's Apify Store page, not this tracker.
